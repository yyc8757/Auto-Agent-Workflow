# Auto-Agent-Workflow (Under Active Development 🚧)

## Introduction
An experimental multi-agent workflow system designed for automated code refactoring and long-context knowledge retrieval. 

Currently migrating core reasoning modules to evaluate the performance of **Xiaomi MiMo-V2.5-Pro**.

## Architecture (WIP)
- **Agent Framework:** Based on LangChain & Dify
- **LLM Engine:** Evaluating MiMo-V2.5-Pro for complex tool-calling capabilities.
- **RAG Module:** Multi-modal document parsing pipeline.

*Note: The source code is currently in a private repository for security reasons during the internal testing phase. It will be open-sourced after the API migration and stability testing are completed.*
